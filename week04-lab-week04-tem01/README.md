## Week 04 Group Session

### PART A

You will consolidate your HW10 assignment. The data files are already in this repo. Note that you may use the base R functions for this part of the lab.

### PART B

You will generate a tidy table named `dat.long` from the two data files. This requires that you identify what constitutes a unique variable and what constitutes an observation. If a variable can be identified as ordinal (quantitative), it should be stored as a number. For maximum credit, you will complete this task in a single series of piping operations. The final output should be devoid of duplicate columns. 

> Hint: Parts of this worklfow will benefit from case_when() and str_detect() functions.
