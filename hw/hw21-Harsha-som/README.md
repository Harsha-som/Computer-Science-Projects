## Homework 21

You are handed a dataset, `census_income.csv`, that lists median household income for 2018 by state (including DC and Puerto Rico). In your report to a client, you wish to summarize the 52 income values using the traditional standard deviation. However, doing so implies that the income dataset follows a normal distribution. Before attempting to characterize its spread using the standard deviation, you want to compare its normal q-q plot to normal q-q plots from simulated datasets pulled from a normal distribution whose mean and standard deviation match those for your actual income data.

You will generate 16 faceted normal q-q plots of the simulated datasets. You will also generate a normal q-q plot of the actual data. The goal is to use the 16 simulated batches to assess the likelihood that the actual income data are consistent with what one would expect given a normally distributed dataset. Note that you might want to generate different realizations of the 16 plots for yourself to help develop a better intuitive feel for what a normally distributed income dataset might look like. If you want your 16 plots to look the same when the script is run by another user, you may precede the creation of the simulated values with the `set.seed()` function. Simply pass a numeric value of your choosing to the function. Different `set.seed` values generate different sets of random values.

You will generate all plots using `ggplot2`. Any data manipulation/creation will make use of `dplyr` when possible. Your deliverable will consist of an Rmarkdown file with the 16 simulated normal q-q plots (as well as the actual income normal q-q plot), and a narrative defending your assessment as to whether income follows a normal distribution. Be thorough in your write-up since this will make up half of your grade. Set `code-folding` to `hide`. 

> Note that if you want to prevent R from using scientific notations in the plots and in an inline code chunk when displaying large numeric values, you can add the line of code `options(scipen = 99)` at the beginning of the R script.
