## Homework 27

For this assignment, you will explore the relationship between Iris petal area (`petal.area`) and petal length (`petal.length`). More specifically, you will explore the petal length effect on petal area. In this assignment, you will:

* Generate a scatter plot of the bivariate data;
* Fit a first order polynomial to the data;
* Generate a residual-dependence diagnostic plot;
* Generate a spread-location diagnostic plot;
* Include a narrative that will define the first order polynomial you are fitting to the data and describe how well this model fits the data. Are the desired characteristics of the fitted model met based on the diagnostic plots?


Note that the dataset is in long form. The `sample` column provides you with each observational unit (a single iris plant). You will therefore need to restructure the file so as to make it suitable for a bivariate analysis.

`iris_measurements.csv` documentation:

* `sample`:  Unique plant observation   
* `type`: measurement type   
* `value`: measured value
