Spread in mean values is about half that of the residuals’

library(ggplot2)
library(dplyr)
library(tidyr)
set.seed(10) #set seed to get same random values every run

n <- 200  # Number of simulated values in each batch
a <- rnorm(n, 14, 2) #create random normal batch
b <- rnorm(n, 10.9, 2)
df <- data.frame( x = c(a, b),
                  group = c(rep("a", n), rep("b", n)))

rf <- df %>%   # Normalize values to global mean
  mutate(norm = x - mean(x)) %>%   # Normalize values to global mean
  group_by(group) %>% 
  mutate( Residuals  = norm - mean(norm),    # Extract group residuals
          `Fitted values` = mean(norm)) %>%   # Extract group means
  ungroup() %>% 
  select(Residuals, 'Fitted values') %>% 
  pivot_longer( names_to = "type", values_to = "Values",
                cols = everything()) %>% 
  group_by(type) %>% 
  arrange(Values) %>% 
  mutate( fval= (row_number()-0.5)/ n()) #calculate f val

#plot of separate graphs
# ggplot(rf, aes(x = fval, y = Values)) + 
#     geom_point(alpha = 0.3, cex = 1.5) +
#     xlab("f-value") + ylab("Values") +
#     facet_wrap(~type)

#Create R-F spread plot
ggplot(rf, aes(x = fval, y = Values, col = type)) + 
    geom_point(alpha = 0.3, cex = 1.5) +
    xlab("f-value") + ylab("Values") + ggtitle("R-F spread plot")

It’s clear from this r-f spread plot that the spread of the mean values (between batches a and b) is about half of that of its residuals. The means span 2.52 units (about -1.26 to +1.26 on the y-axis) while the residuals span about 5 units, from about -2.5 to 2.5 (ignoring extremes). This suggests that the groups a and b do not explain much of the variability in the data. We can vertify this by eyeing where the spread of the fitted values coincides with the spread in residuals. We can see the f-values goes from about .25 to about .74 or 25% to 74%. So the difference in means explains about 49% (74%-54%) of the variability in the data.
